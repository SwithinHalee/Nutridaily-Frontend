# NutriDaily Frontend

Aplikasi web NutriDaily, platform katering dan manajemen gizi harian yang menyajikan menu terpersonalisasi, estimasi kebutuhan kalori (TDEE), penyesuaian jadwal menu, serta verifikasi mutu bahan pangan.

## Fitur Utama

- **Kalkulator TDEE**: Perhitungan estimasi kebutuhan kalori harian berdasarkan profil fisik dan target kesehatan.
- **Katalog Menu**: Informasi komposisi gizi makro (kalori, protein, karbohidrat, lemak), metode masak, dan transparansi bahan baku.
- **Penjadwalan & Swap Menu**: Penyesuaian dan pertukaran menu harian untuk jadwal katering aktif.
- **Verifikasi Clean Label**: Verifikasi kode batch produksi, sertifikasi uji laboratorium, dan dokumen sertifikat PDF.
- **Dashboard Langganan**: Pemantauan status paket, kalender pengiriman, alamat penerima, dan riwayat transaksi.

## Teknologi

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- jsPDF

## Memulai

### Prasyarat

- Node.js (versi 18 atau lebih baru)
- npm

### Instalasi dan Menjalankan

1. Clone repositori:
   ```bash
   git clone https://github.com/SwithinHalee/Nutridaily-Frontend.git
   cd Nutridaily-Frontend
   ```

2. Instal dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```

Buka `http://localhost:3000` di peramban.

### Build Produksi

```bash
npm run build
npm run start
```
